Two memories about possibly the same fact. Decide the relation.
- same: they say the same thing (the new one adds no new information).
- replaces: the newer statement supersedes the older one (plans changed, preference
  changed, the old one is wrong). The old fact had a validity window that has ended.
- unrelated: they are different facts that merely resemble each other.
